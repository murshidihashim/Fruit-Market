# 🍎 Fruit Market

*Buy fresh. Sell fast. Undercut your rivals before it all goes bad.*

A quick trading game for Android and the web, based on the Fruit Market board game designed by Murshidi bin Md Hashim.

**Modes:** solo vs computer shopkeepers (Easy/Normal/Hard), pass-and-play, private online rooms, quick match with strangers, the Market League (6 stages), and a daily challenge with a replay-checked leaderboard. A guided first game, achievements, unlockable stall colours, optional music and colour-blind freshness patterns are built in.

## Tech

- TypeScript + [Preact](https://preactjs.com) UI, built with [Vite](https://vitejs.dev)
- Wrapped as a native Android app with [Capacitor](https://capacitorjs.com)
- Works fully offline. No servers, no tracking.

```
src/engine/   rules (game.ts), cards and numbers (data.ts), computer players (ai.ts)
src/ui/       screens and components
tests/        engine tests (vitest)
scripts/      balance simulation, headless playthrough, icon generator
android/      native Android project (generated by Capacitor, with custom icons and signing)
```

## Develop

```bash
npm install
npm run dev          # play in the browser at http://localhost:5173
npm test             # rules tests (plays 200 full games)
npm run simulate     # balance report: AI win rates, average scores
npm run build:single # one self-contained HTML file in dist-single/
npm run lint         # ESLint (correctness rules; style is not enforced)
npm run typecheck    # TypeScript for the app and the server
npm run test:e2e     # browser tests: solo game, performance budget, online match, quick match
npm run perf         # performance budget only (DOM size, long tasks at 4x CPU slowdown)
```

Every push and pull request runs all of these in CI (`.github/workflows/ci.yml`).

## Android

```bash
npm run android:sync              # build web app and copy into android/
cd android && ./gradlew assembleDebug
```

Needs the Android SDK (Android Studio). Or just push to GitHub: the **Android build** workflow makes a debug APK and, once signing secrets are set, a release `.aab` for Play.

## Tuning the game

All the numbers live in `src/engine/data.ts`: fruit costs, shelf lives, customer cards, events, favours and upgrades. After changing them, run `npm run simulate` to check that games stay balanced.
