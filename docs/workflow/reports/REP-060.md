## WHAT CHANGED

- **One palette.** src/ui/palette.ts names every colour the interface and sprites use (197). styles.css reads them as variables from the generated palette.css. The move is lossless: putting the palette values back gives the old files exactly. The old colours are kept as c_xxxxxx entries; PLAN-033 merges them into the guide roles. A test fails on any colour written outside the palette.
- **No emoji.** Seat buttons (Computer, Friend), the waiting, special, heard and happy marks on customers, the Favoured Trade card and several labels now use text or pixel icons (new hourglass and ear icons). A few plain glyphs stay (the close, tick, arrow and menu marks). A test enforces this.
- **Sizes.** The allowed sprite sizes are defined and a test blocks any new off-list size. The 29 existing off-list sizes stay until PLAN-033, because changing a size changes the layout.
- **Guide.** docs/ART-STYLE.md approved and updated.
