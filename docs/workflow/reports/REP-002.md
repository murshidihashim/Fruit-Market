## Deviation from the plan (needs your confirmation)

PLAN-001 said "a private Cloudflare preview URL; if it isn't free, local preview steps".
Cloudflare's docs state that preview and version URLs **are not generated for Workers that implement a
Durable Object**, and Fruit Market's server uses Durable Objects for rooms. So I used the next closest
option: a second, separate Worker (`fruit-market-staging`). This is recorded as **DEC-006**.
- Cost: no new paid service. It runs within the Cloudflare plan you already use; usage is tiny.
  Your plan type is still unknown (DEC-005).
- "Private" means unlisted: anyone with the link can open it.
- To undo: delete the `fruit-market-staging` Worker in Cloudflare and remove the `preview` job.

## Risks and costs
- Expected extra cost: RM0 (no new paid service). Not yet confirmed against your plan type.
- Until branch protection is on, a direct push can still skip CI, but it can no longer reach players
  without *Deploy*.
- If CI is red, the preview isn't updated; the live game is unaffected.
