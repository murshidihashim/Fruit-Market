Every REP-140 finding was worked on except C-02 (Nest Egg in the Sprint), which is a balance choice for the owner.

The work was done in two waves by helpers working side by side:
- **Wave 1:** player fixes, accessibility and small phones, and code cleanup.
- **Wave 2:** the code was split into smaller parts, the tests were rewritten to check behaviour, the styles were merged, and the screens load on demand.

Each part was reviewed and merged, then checked again together.

## 1. What changes for players

- **League:** stage 11's "Let no fruit spoil" star can now be earned (C-01).
  - It was met in 0% of test games before and is met in 63% now. The stage is no harder to clear.
  - This means the gold trophy "Earn all 42 stars" can now be won.
  - The change: the Soft piece in stage 11's starting stock is now an apple, which Postman Pip buys on day 1.
- **Main buttons in view (B-01):** the Sprint and Daily intros, the League and How to play keep their main button on screen on small phones.
- **Small phones (B-02, B-03, B-06, B-07):**
  - At 320 wide the sales pop-up fits on screen.
  - On short phones the table fits and only the market scrolls.
  - Tips no longer cover buttons.
  - Long event names wrap.
- **Keyboards and screen readers (B-08 to B-11):**
  - Focus rings show where you are.
  - A whole game can be played with the keyboard.
  - Customer cards open from the keyboard and have spoken names.
  - Small text is larger, and faint text has stronger contrast.
- **Words:**
  - Quick Match and Private Room explain when computers join (B-12, B-13).
  - Pass & Play results name the players (B-14).
  - Sharing says "Link copied" or "Could not copy" (B-18).
  - "Stall" is used everywhere (B-19).
  - How to play's sale example matches the rulebook (C-06).
- **Fewer taps (B-15, B-20):**
  - The in-game menu has Fast play, Reduced motion and How to play.
  - Continue goes straight back into your game.
  - New game asks "Keep my game" or "Start over".
- **Other fixes:**
  - An order star goes to the right seat even when a player uses a rival shopkeeper's name (C-03).
  - A save from before version 1.2 shows the older-rules notice (C-05).
  - The event pop-up is solid (B-05).
  - Long names wrap (B-17).
  - The set-up pages are narrower on computers (B-21).
- **Loading (A-08):**
  - Home needs about 30% less script before it shows (main script 588 kB to 407 kB; gzip 204 kB to 142 kB).
  - The game and rarely used pages load in the background.
  - Every page still opens offline once the game has loaded.
  - The Android build carries every file inside the app.
- **One small data change (A-06):**
  - A signed-in player's saved name is now cleaned as online rooms clean names: one space between words, and wide letters made plain.
  - No limit or anti-abuse rule changed. Room names are unchanged; in a 73-name table, 14 account names change.

Nothing else on screen should look different. Section 2 shows how this was checked.

**Performance budget.** It failed on this shared machine: the longest task was 307 ms and 236 ms, against a 200 ms limit.
- The game screen opened in 254 ms (limit 350).
- Slow frames were within budget.
- The build before wave 2 failed the same check here today in 8 of 9 runs (up to 488 ms).
- GitHub's test machine normally passes it at about 63 ms; its result on the preview will decide.

**The random walk.** I wrote an extra check of my own, independent of the helpers' screenshots. It is now `scripts/walk-compare.cjs`.
- It clicks through the game at random on two builds with exactly the same choices, at 320, 360, 390 and 1280 wide.
- After each step it compares how every element is drawn.
- Comparing wave 2 with the build before it, it first found:
  - the "Game in progress" pop-up and the account pop-up had lost their square ticket-style frame and buttons;
  - the account panel had lost its background and border;
  - How to play's F/O/S lamps had shrunk;
  - keyboard focus left the Back button on the way back from the Public rooms page.
- Cause: the style merge had removed about 1,000 style lines only because no screen in the helper's screenshots used them.
- Fix: all of those lines were put back, and the focus was fixed.
- The online focus fix now has a browser check.
- After the fixes, 48 new walks of 100 steps each found no differences. The only exceptions were margins with identical boxes, and Rush timing (the Rush length was measured equal).

## 3. What changed in the code (no change for players)

- **Split into smaller parts (A-02):**
  - The game controller (559 lines) became plain functions you can test: turns, the beat player, step kinds, seats and the day's words.
  - `Game.tsx` went from 341 to 189 lines.
  - App, Online, Set-up, League and the account panel were split.
  - The engine's `resolve` and `startDay` and the room server's `dispatch` were each split into small steps with the same behaviour.
  - No function is now over 100 lines.
- **Tests (A-01, A-10):**
  - Source-text checks went from about 257 to 34. The rest are behaviour tests or browser checks: table checks, layout checks and style checks in the solo game.
  - New tests drive the game controller directly: the buy queue, Undo mid-flight, the Pass & Play hand-over, the online queue, and a whole game.
  - The server's web addresses have tests.
- **Styles (A-05):**
  - Styles are smaller: 365 kB to 323 kB built.
  - Classes styled in 2 or more files: 359 to 296.
  - `#app` rules: 1,361 to 1,161.
  - A new test stops the layering from growing back.
- **One source each (A-03, A-06):**
  - The freshness price rule and stage words now come from the engine.
  - Mode names have one source, and the shopkeeper key is read in one place.
  - Names are cleaned by one function shared with the server.
- **Removed (A-04):**
  - the switched-off guided first sale, the unused character picker and the old Home street;
  - unused helpers and about 180 style rules.
- **Records (A-07, A-09, A-11):**
  - Stale comments fixed.
  - Every ignored error now has a reason.
  - The records check warns when a "candidate" release is already tagged; it found release 1.3.0, now corrected.
  - The release check no longer names the assistant.
- **Night speed (C-04):** the table under a sheet is now measured once, not once per row.
  - On this machine slow frames in the Rush fell (median 39 to 28).
  - The longest task did not clearly change, so C-04 is only partly met.

## 4. Still open

- **C-02, Nest Egg in the Sprint:** the owner's choice. Options:
  - take it out of the Sprint's offer;
  - give a smaller bonus in short games;
  - leave it.
- **Private Room, host alone:** a host whose other seats are all "+ Computer" cannot press Start.
  - The server needs 2 people, unless 60 seconds have passed.
  - That later start fills every seat with a computer and ignores the computers the host chose.
  - Fixing it means changing the room server's start rule, so it needs the owner's approval.
- **"Home" and "Market":** both names are still used for the same tab. The owner's choice.
- **Not fully fixed:**
  - Names are still cut in 6-stall table boxes at 320 to 390 ("Uncle Benny…").
  - The level word is cut in a full 6-stall set-up at 320 to 360.
  - Ticket names and card numbers stay at 7 to 7.5 px, the design's own size.
  - Night dims the rows to low contrast.
- **Found during the work, not fixed:**
  - In an online match, focus drops to the page when "Leave the match?" opens, as it did before. Tab still stays inside the box.
  - With Reduced motion, "LAST 3 DAYS" can stay up if Start buying is tapped within about a second.
  - Some pop-ups and the night moon still move in steps.
- **Merge author:** one wave 1 merge (f2361fb) shows the assistant as its author. It cannot be changed without rewriting the shared history.

## 5. Risks

- **Styles:** the style regrouping still relies on the screenshots for which rules meet.
  - 48 random walks found nothing more.
  - Screens that no walk reached could still differ.
  - The owner's look at the preview is the last check.
- **Loading on demand:** a player who has the game open while a new version is published could, in theory, open a page whose file has gone.
  - The game fetches every page in the background soon after it opens, which makes this unlikely.
  - If it happens, the page says it could not load and offers Try again.
