## SUMMARY

A **Full screen** button sits in Settings and in the pause menu. It uses the browser's Fullscreen API, so it shows on Android Chrome, desktop browsers and iPad. iPhone Safari has no full-screen mode for web pages, so there the button is hidden and Settings explains how to get full screen with Add to Home Screen. Browsers only allow full screen from a tap, so the game cannot start in full screen by itself. It is part of the 1.2.0 candidate.
