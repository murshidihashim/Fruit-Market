## HOW IT WORKS

- **Undo (Design 1).** The server saves the state a person's own buying turn began in (never sent to anyone). A new undo request is accepted only from the active player, in the buying phase, if something changed this turn, and on the current version. It puts the shelf, cash and market back, tells everyone ("<name> took back their purchases"), and can be used again after buying again. A repeated request does nothing. It is cleared when a computer plays the seat, the turn ends or a new match starts. The button now shows online too, enabled once you have bought something.
- **Rename.** A rename request is accepted in the lobby only, with the same cleaning as joining; a refused or empty name keeps the old one. In the lobby your own name is an editable box.
- **Message version.** Phones and server now check a message version as well as the rules version, so an older build gets the update message instead of joining. The rules version did not change, so daily boards are not reset.
