# Fruit Market: real-device checklist (PLAN-032)

One page to run on each real phone before a release. Tick each line; note the phone, the browser or app, and the date.

| Phone and browser | Date | Who |
|---|---|---|
| | | |

**Start**
- [ ] The home screen opens within a few seconds; the title and buttons are readable and nothing is covered.
- [ ] New game: the name box is blank; tapping it opens the keyboard; a blank name still starts a game.
- [ ] Pick a shopkeeper; computer stalls take the others; start the game.

**A full game on one device**
- [ ] Play 10 days to the end; every button can be tapped with a thumb; no text is cut off.
- [ ] The customer queue, the Wholesale Market and your stall fit on the screen without sideways scrolling.
- [ ] Undo (the arrow) puts back what you bought this turn.
- [ ] Rotate the phone and back: the game keeps its place.
- [ ] Switch to another app for a minute and back: the game resumes.
- [ ] Sound and haptics switches work; music is off by default.

**Online room (two phones)**
- [ ] Create a room and join by the link; both see each other; change your name in the lobby with Rename.
- [ ] Pick different shopkeepers; ready up; the host starts.
- [ ] Buy something and use undo: the other phone shows "took back their purchases" and the market matches.
- [ ] Turn one phone's network off for 20 seconds and back: it rejoins its seat.
- [ ] Close the app on one phone, reopen it from the link: it returns to the same seat.
- [ ] Finish the match; rematch works.

**Release**
- [ ] The version number on the settings screen matches the release.
- [ ] Nothing says "Farmers Market", "shop", "Not so" or any retired name (see Naming_Audit).

Results are recorded in the PLAN-032 report; a failed line becomes a bug report with the phone and steps.
